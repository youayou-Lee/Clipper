## 4. 过程中发现并修复的真实缺陷

1. **GBK 控制台崩溃**(PR #44):cmd 码页下打印 `⚠` 抛 UnicodeEncodeError,`paste`/`--json`
   回显剪贴板任意字符同样崩溃——真实 Windows 用户必踩。修复:CLI 入口统一降级 errors 策略,
   复现测试永久留回归集。演练日志里 `⚠ → ?` 即修复的现场效果。
2. **0600 权限测试平台假设**(PR #41):NTFS 无 POSIX 权限位,测试在 Windows 必败。修复:skipif。
3. **会话隔离**(运维发现,非缺陷):ssh 会话与交互桌面会话的剪贴板互不可见(窗口站隔离),
   所有"写地址→读回"验证必须在同一交互会话内闭环——这本身就是 defense-mapping §3
   "检测点要看清信号在哪个会话/窗口站可见"的活教材。
